# AdaDiag — runtime dependencies.
#
# Deliberately small. DGL is NOT required: the incident graphs have 10–21 nodes, so the
# GraphSAGE layers are implemented with dense batched matmuls (src/adadiag/encoders.py).
# That removes the hardest version-pinning problem in reproducing TVDiag and makes the
# whole pipeline runnable on CPU.
#
#   pip install -r requirements.txt
#
# Verified on Python 3.13 / Linux, CPU only; no GPU is needed. On 2 CPU cores a 5-arm,
# 5-seed sweep takes ~16 min on Hotel Reservation and ~34 min on GAIA.

scipy>=1.10           # paired t-tests in scripts/make_report.py; tested on 1.18.1
pytest>=7.0           # tests/
matplotlib>=3.7      # figures in results/paper_comparison/ only; tested on 3.11.2
